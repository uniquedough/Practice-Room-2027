# Curriculum map
Each row is a module, not a fixed weekly schedule. Move on when the learner can demonstrate or self-report the checkpoint comfortably three times. Revisit skills in musical contexts.

| ID | Piano | Exercise / checkpoint |
|---|---|---|
| P1 | Keyboard geography, posture, pulse | Find all Cs; play C4 D4 E4 F4 G4 with RH 1–5, quarter notes at 60 BPM |
| P2 | Triads, hands separately | C, Am, F, G; one chord per 4 beats; LH roots separately |
| P3 | Inversions, economical movement | C4 E4 G4 → C4 F4 A4 → B3 D4 G4 → C4 E4 G4; relaxed RH, 60 BPM |
| P4 | Hand independence | LH root on beat 1, RH triad on beats 1 and 3; 4-bar loop |
| P5 | Rhythm, arpeggios and voicing | RH 1–3–5–3 chord tones as eighth notes; steady LH root |
| P6 | Major/minor scales, optional notation | One octave C major RH and LH separately; explain thumb crossing |
| P7 | Sevenths, dynamics and songwriting | Play Cmaj7–Am7–Dm7–G7, choose close voicings, write original motif |
| P8 | Improvisation, repertoire | Build 8-bar melody with rests, record own progress if desired |

| ID | Guitar | Exercise / checkpoint |
|---|---|---|
| G1 | Tuning, holding, pick, clean notes | Identify six strings; play frets 0–1–2–3 on one string, no buzz |
| G2 | Open chords | Em (022000), Am (x02210), C (x32010), G (320003); each string rings as intended |
| G3 | Chord changes and pulse | Em–G–C–Am, four downstrums per bar at 60 BPM |
| G4 | Eighth-note strumming and muting | Down/up counting 1 & 2 & 3 & 4 &, muted exercise then chords |
| G5 | Power chords and movable shapes | E5 022xxx, G5 355xxx; relaxed fretting and muted unused strings |
| G6 | Pentatonic and picking | A minor pentatonic in fifth position, alternate pick four notes at a time |
| G7 | Barre alternatives and arpeggios | F xx3211 first; fuller barre only if comfortable, pick chord tones individually |
| G8 | Lead/rhythm writing | Build two complementary 4-bar original parts and maintain pulse |

| ID | Bass | Exercise / checkpoint |
|---|---|---|
| B1 | Tuning, pulse, alternating fingers | Open E and A, four quarters per bar; alternate index/middle or use pick |
| B2 | Fretting and muting | E string 0–1–2–3; stop each note before next, mute unused strings |
| B3 | Roots and chord changes | Am–F–C–G: A string 0, E string 1, A string 3, E string 3 |
| B4 | Eighth-note groove and rests | Root on 1, 2 &, 4; silent otherwise; count subdivisions |
| B5 | Fifths, octaves and chord tones | A string 0, E string 0, G string 2, A string 3 = A E A C; adapt positions |
| B6 | Scale navigation and passing tones | A natural minor, stepwise movement between chord roots |
| B7 | Syncopation, articulation and lock-in | Accent offbeats, compare against click or drum track |
| B8 | Melodic bass and composition | Write an independent 4-bar motif with chord tones on strong beats |

Shared concepts: pulse → subdivisions → pitch names → intervals → triads → scale degrees → diatonic harmony → form and improvisation. Theory need not precede playing. Treat a guitar chord player learning piano as a theory transfer case, not an advanced pianist.
