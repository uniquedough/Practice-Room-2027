# Changelog

## 1.8.0 — 2026-11-25
First packaged prototype; version chosen to reflect a feature-rich initial scope, not prior releases.
- Two reusable skills and 24 progressive instrument modules.
- Adaptive lesson planning, self-reported progress, artist/genre-inspired exercises and resource guidance.
- Deterministic chord, scale, fretboard and open guitar shape calculations.
- Original Type 1 MIDI practice engine and three example tracks.
- Automated unit tests, GitHub Actions workflow and manual plugin acceptance plan.

Not yet verified: actual ChatGPT installation, script execution in installed host, public GitHub publication or directory review. No real-time performance grading or persistent account storage.
